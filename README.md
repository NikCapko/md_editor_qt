# Markdown Editor

Простой редактор Markdown-файлов с подсветкой синтаксиса, боковым оглавлением, поиском/заменой и экспортом в PDF/EPUB.

## Возможности

- **Подсветка Markdown**: заголовки, жирный, курсив, код, ссылки
- **Номера строк** с автоматическим расширением
- **Боковое оглавление** — навигация по заголовкам документа
- **Подсветка активной строки** (цвет зависит от темы)
- **Поиск и замена** с поддержкой регулярных выражений, учёта регистра и истории
- **Экспорт в PDF и EPUB** (одна колонка)
- **Метаданные книги** (.bnf) — название, автор, теги, описание, избранное
- **Светлая и тёмная тема** с сохранением выбора
- **Опциональная коррекция текста**

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate.fish
pip install -r requirements.txt
python editor.py [файл.md]
```

## Использование

1. **Файл → Открыть…** — выберите `.md` файл.
2. Редактируйте текст. Активная строка подсвечивается.
3. Используйте боковое оглавление для быстрой навигации по заголовкам.
4. **Ctrl+F** / **Ctrl+R** — поиск и замена с поддержкой regex.
5. **Вид → Тема** — переключение между светлой и тёмной темой.
6. **Файл → Метаданные книги** — редактирование `.bnf` файла (название, автор, теги).
7. **Файл → Экспорт в PDF/EPUB** — сохранение документа в нужном формате.

## Структура файлов

- `editor.py` — основной файл редактора
- `export_parallel.py` — модуль экспорта в PDF/EPUB
- `text_corrector.py` — опциональный модуль коррекции текста
- `*.md` — редактируемые Markdown-файлы
- `*.bnf` — метаданные книги (JSON)

## Требования

- Python 3.8+
- PySide6
- reportlab (для экспорта в PDF)

## Примечания

- При сохранении метаданных создаётся файл `.bnf` рядом с `.md` файлом
- Тема сохраняется в `QSettings` и применяется при следующем запуске
- История поиска/замены и тегов сохраняется между сессиями
