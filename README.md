# Parallel Translation Editor

Редактор для книг с параллельным переводом.

## Возможности

- **Две панели**: слева оригинал (`.en.md`), справа перевод (`.ru.md`)
- **Номера строк** у обоих редакторов
- **Подсветка активной строки** (жёлтым)
- **Синхронизация прокрутки** и активной строки между панелями
- **Подсветка Markdown**: заголовки, жирный, курсив, код, ссылки, списки, цитаты
- Открытие пары файлов (автоматический поиск `.ru.md` рядом с `.en.md`)
- Сохранение обеих сторон, индикатор несохранённых изменений (`*`)

## Запуск

```bash
pip install -r requirements.txt
python editor.py
```

## Горячие клавиши

| Действие              | Клавиши        |
|-----------------------|----------------|
| Открыть пару          | Ctrl+O         |
| Сохранить             | Ctrl+S         |
| Сохранить как…        | Ctrl+Shift+S   |
| Отменить / Повторить  | Ctrl+Z / Ctrl+Y|
| Выход                 | Ctrl+Q         |

## Использование

1. **Файл → Открыть пару…** — выберите `.en.md`, программа сама найдёт соседний `.ru.md`.
2. Редактируйте текст. Активная строка подсвечивается в обеих панелях.
3. Прокрутка синхронизирована (можно отключить в меню **Вид**).
4. **Ctrl+S** сохраняет оба файла.
